Un quatrième guide rejoint le menu **Guides** : **Nouveau projet : bien commencer**. Il rassemble ce qu'on met en place le premier jour d'un projet mené avec Claude Code :

- un **CLAUDE.md de départ**, court, avec un modèle à copier ;
- les **skills et agents** utiles dès le début, et l'ordre dans lequel préférer un test, un hook, une règle ou un agent ;
- le **plan, les Nouveautés et la livraison** avec cadence ;
- les **garde-fous** : tests, revue UX au téléphone et sur grand écran, confidentialité de ce qui est publié ;
- la **gestion des tokens** en six habitudes : une session par chantier, `/clear` en fin de lot, un contexte relu à chaque tour, la délégation aux sous-agents, des mémoires courtes et un index de mémoire qui reste sous sa limite ;
- une **liste de contrôle du premier jour**, à suivre dans l'ordre.

Le guide est aussi listé sur l'accueil et dans « Les autres guides » en bas de chaque guide.
