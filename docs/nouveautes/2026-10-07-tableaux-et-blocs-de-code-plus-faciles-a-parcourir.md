Sur la page hermes-agent, le tableau de comparaison se lit mieux à 320 px : il prend plus de place sur l'écran et sa première colonne reste affichée quand on le fait défiler de côté. Les tableaux de l'étude de cas aetherwx-encyclopedia ont maintenant un cadre qui montre qu'ils défilent. Les blocs de code et les tableaux qui défilent s'atteignent au clavier (Tab), avec un nom lu par les lecteurs d'écran. Dans la page Nouveautés, chaque capture est décrite par le texte écrit pour elle, et les descriptions des cartes de l'index des études de cas n'affichent plus d'accents graves bruts autour des commandes.
