Sur la page d'accueil, la petite ligne orangée au-dessus du titre, « Codex Claude Code · guides · projets », est désormais posée sur une pastille sombre, comme le sur-titre des autres pages du site.

- **Plus lisible** : posée directement sur l'image de fond, elle manquait de contraste sur une tablette ; sur sa pastille, elle se lit à toutes les largeurs d'écran, en haut de page comme après un léger défilement.
- **Au téléphone**, la pastille passe sur deux lignes quand le texte ne tient pas sur une seule.
